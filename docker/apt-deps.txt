# DAAAM 工作区所需的系统包（apt）。
#
# 来源：在已导入全部同级仓库的工作区里执行
#   rosdep install --from-paths src --ignore-src -r -y --rosdistro=jazzy --simulate
# 得到的安装清单（2026-10-14，对应 install/packages.yaml 中的分支）。
#
# 为什么要固化成镜像层：rosdep 安装的系统包写在容器自己的文件系统里，不在
# daaam_workspace 卷中；`docker compose run --rm` 退出后会消失，而卷里编译好的
# 产物依赖这些库。工作区发生变化（新增/升级同级仓库）后，请重新执行上面的
# --simulate 命令并更新本文件。
#
# 构建：docker compose build daaam-ws   （见 docker/Dockerfile.deps）
