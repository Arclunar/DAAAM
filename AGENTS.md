# Agent Guidelines

## Changelog

- Every repository modification must be recorded in `CHANGELOG.md` as part of the same task.
- Add entries under the current date using the categories `Added`, `Changed`, `Fixed`, or `Removed` as appropriate.
- Describe the user-visible or developer-visible impact concisely; do not list generated files or implementation trivia.
- Documentation-only and configuration changes must also be recorded.
- Before finishing, verify that the changelog entry accurately reflects all modifications made during the task.
